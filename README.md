# Binary Classification using Machine Learning

## 📌 Overview
This project implements a Binary Classification model using Machine Learning. It uses Logistic Regression to classify breast tumors as Malignant or Benign.

## 📊 Dataset
- **Dataset:** Breast Cancer Wisconsin Dataset
- **Source:** Scikit-learn built-in dataset
- **Total Samples:** 569
- **Features:** 30 numerical features
- **Target Classes:** Malignant and Benign

No external CSV file is required.

## 🛠️ Technologies Used
- Python
- Pandas
- Scikit-learn

## ⚙️ Installation

Install the required libraries:

```bash
pip install pandas scikit-learn
```

## ▶️ How to Run

1. Clone or download this project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python binary_classification.py
```

## 📈 Model Evaluation
The model is evaluated using:
- Accuracy Score
- Confusion Matrix
- Precision
- Recall
- F1-Score

## 🧠 Algorithm
**Logistic Regression** is used to predict one of two possible classes based on input features.


## 🎯 Objective
To understand the basic workflow of a binary classification problem, including dataset loading, preprocessing, model training, prediction, and evaluation.

## ⚠️ Disclaimer
This project is intended for educational purposes only and is not intended for medical diagnosis.
